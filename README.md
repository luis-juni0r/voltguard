# voltguard
O VoltGuard é um sistema de monitoramento elétrico baseado em IoT, desenvolvido para identificar consumo anormal de corrente em equipamentos, prevenir danos causados por instabilidade na rede elétrica (quedas e picos de tensão) e gerar relatórios técnicos que apoiam a tomada de decisão sobre manutenção e uso racional de energia.
